### Hackers Use Autonomous AI Agents to Exploit Medical Software Zero-Day

China-linked attackers reportedly deployed an open-source autonomous AI tool called Cairn to discover and exploit a zero-day vulnerability in MONAI Label medical software. The breach allowed the threat actors to gain root access on a university server. Organizations running open-source medical applications should audit systems for unexpected activity and maintain strict access controls.

### Critical GnuPG GPGME Vulnerability Threatens Application Data

A critical memory corruption flaw in the GPGME library can be triggered by processing an OpenPGP key containing an unusually long user ID. The GnuPG project reportedly warned that the bug could enable attackers to extract private data from applications relying on the library. Developers and administrators using GPGME should update their installations promptly.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/11/gnupg-warns-critical-gpgme-flaw-could.html)</span>

### Meta Muse Flaw Exposes Private Chats and Credentials via Malicious Webpages

Researchers demonstrated that opening a single malicious webpage could allow attackers to hijack Meta Muse and extract private conversations and memories without user authorization. The exploit can reportedly be extended to access stored credentials managed by the AI assistant. Users should remain cautious when clicking on unverified web links.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/11/a-single-malicious-webpage-let.html)</span>

### WhatsApp Fixes Android Vulnerability Reportedly Exploited in Scam Campaigns

Meta has released security updates for WhatsApp, patching an Android flaw tracked as CVE-2026-23871. The vulnerability was reportedly exploited in active campaigns to increase the credibility of scam messages sent to users. WhatsApp users are advised to update their app to the latest version immediately.

<span class="brief-src">Sources: [The Hacker News](https://thehackernews.com/2026/11/whatsapp-patches-3-security-flaws.html), [SecurityWeek](https://www.securityweek.com/whatsapp-fixes-flaw-uncovered-while-disrupting-scam-campaign/)</span>

### CISA Adds Actively Exploited VMware, Cisco, Apache, and SAP Flaws to KEV Catalog

The Cybersecurity and Infrastructure Security Agency added four security flaws affecting Broadcom VMware vCenter, Cisco Expressway, Apache Roller, and SAP NetWeaver to its Known Exploited Vulnerabilities catalog. CISA warned that threat actors are actively exploiting these bugs in real-world attacks. System administrators should prioritize applying manufacturer patches for affected software.

<span class="brief-src">Sources: [The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-critical-vmware-cisco.html), [CISA advisories](https://www.cisa.gov/news-events/alerts/2026/11/20/cisa-adds-four-known-exploited-vulnerabilities-catalog)</span>

### Third-Party Service Provider Breach Exposes Financial Customer Data

J.P. Morgan Chase issued a warning after a cyberattack on a third-party vendor exposed customer personal and marketing information. The incident reportedly impacted data associated with Chase, Visa, and Mastercard customers. Account holders should watch for sophisticated phishing attempts and monitor financial statements closely.

<span class="brief-src">Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/vendor-data-breach-exposes-chase-visa-mastercard-customer-info/)</span>

## What to do this week

- Update WhatsApp and system software to patch known security vulnerabilities.
- Apply emergency updates for enterprise solutions like VMware vCenter, Cisco Expressway, and SAP NetWeaver.
- Be suspicious of unexpected emails or text messages claiming to come from financial providers.
- Avoid opening links from untrusted sources that could trigger web-based assistant exploits.
