### Massive GitHub CI Secret Theft Campaign

An attacker reportedly used thousands of hijacked accounts to deploy a secret stealer across more than 1,800 GitHub repositories. The malicious campaign targeted repository CI environments to extract sensitive credentials and secrets. Organizations using GitHub should audit CI/CD secrets, rotate potentially compromised credentials, and enforce strict authentication controls for developer accounts.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/attacker-targets-60000-github-repositories-in-credential-theft-campaign/), [The Hacker News](https://thehackernews.com/2026/11/4837-hijacked-github-accounts-ran-ci.html)</span>

### ScreenConnect Attacks Impact Managed Service Providers

Hackers are actively exploiting a vulnerability in a third-party extension to bypass authentication on ScreenConnect servers. The campaign has breached multiple managed service providers and deployed unauthorized remote-access clients onto downstream endpoints. ConnectWise has disabled five extensions and advises administrators to review client logs and follow official guidance.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/hackers-deploy-malware-in-fresh-screenconnect-campaign/), [The Hacker News](https://thehackernews.com/2026/11/screenconnect-attacks-target-at-least.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/active-screenconnect-attacks-breach-msps-impact-dozens-of-organizations/)</span>

### Notion AI Transcripts Exposed in Third-Party Breach

Notion revealed that a security incident at its AI service provider, Fireworks AI, exposed customer AI chat transcripts. The compromise affected fewer than one percent of Notion workspaces, with most exposed transcripts reportedly lacking attributable user details. Users of Notion AI are advised to remain cautious about sharing confidential data with integrated AI systems.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/notion-customer-data-compromised-in-fireworks-ai-hack/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/notion-says-fireworks-breach-exposed-customer-ai-chat-transcripts/)</span>

### Active Exploitation of N-central Zero-Day Vulnerabilities

Threat actors have begun exploiting zero-day security flaws in on-premise N-able N-central servers shortly after public disclosure. The vulnerabilities reportedly allow attackers to gain root remote code execution and Windows SYSTEM access, even on previously patched versions. Administrators should restrict network exposure of N-central instances and apply updates from N-able as soon as available.

<span class="brief-src">Sources: [The Hacker News](https://thehackernews.com/2026/11/new-n-central-exploits-work-against.html), [SecurityWeek](https://www.securityweek.com/hackers-target-n-central-zero-days-as-n-able-rushes-patches/)</span>

### Chrome and Firefox Release Updates for Over 180 Flaws

Google and Mozilla have issued critical updates resolving over 180 security vulnerabilities across their browsers. The release of Chrome 157 patches 83 security bugs, while Firefox 160 fixes 99 issues. Users should update both browsers immediately to ensure protection against potential security exploits.

<span class="brief-src">Source: [SecurityWeek](https://www.securityweek.com/chrome-firefox-updates-patch-180-vulnerabilities/)</span>

## What to do this week

- Update Google Chrome to version 157 and Mozilla Firefox to version 160 to patch known vulnerabilities.
- Audit CI/CD pipeline secrets and developer access logs on GitHub repositories.
- Restrict public network access to administrative services such as N-central and review active ScreenConnect sessions.
