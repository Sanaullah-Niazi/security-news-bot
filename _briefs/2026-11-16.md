### Automated Campaigns Target Exposed AI Frameworks for API Keys

Threat actors and automated AI agents are actively scanning public-facing AI management platforms, including LiteLLM and Dify, to locate and extract stored API credentials. Security monitoring observed exploitation attempts targeting LiteLLM and Starlette vulnerabilities, while cloud security research uncovered AI agents conducting automated credential harvesting. Developers and administrators managing self-hosted AI infrastructure should immediately apply available security patches and restrict public access to management interfaces.

<span class="brief-src">Sources: [SANS ISC](https://isc.sans.edu/diary/33522), [The Hacker News](https://thehackernews.com/2026/11/amazon-uncovers-ai-agent-campaign.html)</span>

### Critical Vulnerabilities Expose Industrial Refrigeration Controllers

Security advisories have highlighted multiple security flaws in Danfoss AK-SM800A and Copeland XWEB EVO refrigeration control systems that allow remote attackers to achieve full system takeover without logging in. Scans and active exploitation attempts targeting Copeland devices were detected shortly after disclosure, while Danfoss devices reportedly remain without an official patch. System administrators operating industrial and facility control networks should isolate these devices from direct internet exposure.

<span class="brief-src">Sources: [The Hacker News](https://thehackernews.com/2026/11/six-unpatched-danfoss-refrigeration.html), [SecurityWeek](https://www.securityweek.com/hackers-probe-newly-disclosed-flaws-in-copeland-refrigeration-controllers/)</span>

### Third-Party Vendor Intrusions Compromise Uber and TSMC Data

Separate cybersecurity incidents involving external service providers have led to data leaks at major companies. Uber reported that a third-party services breach exposed personal information for approximately 150,000 individuals, while semiconductor manufacturer TSMC confirmed employee details were leaked online following a cloud vendor security incident. Organizations should review third-party access privileges and ensure external service connections enforce strict authentication requirements.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/uber-data-breach-impacts-150000-people/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/tsmc-employee-data-breach-linked-to-cloud-provider/)</span>

### Long-Standing Linux Kernel Bug Allows Remote Server Crashes

A newly disclosed 11-year-old flaw in the Linux kernel, named NoisyTCP, allows remote attackers to crash affected servers. The vulnerability impacts default setups running widespread software such as Nginx, Apache, and SSH services across most Linux distributions. System administrators should monitor vendor security advisories and apply kernel updates as soon as distribution patches become available.

<span class="brief-src">Source: [BleepingComputer](https://www.bleepingcomputer.com/news/linux/new-noisytcp-linux-kernel-flaw-lets-attackers-crash-servers/)</span>

### Compromised Credentials Lead to Supply Chain Attack on Cursor Marketplace

Development platform Cursor reported that an access key stolen during a breach at Fireworks AI enabled attackers to compromise Anthropic's official Claude Code extension. The stolen key allowed malicious actors to publish a trojanized version of the extension onto Cursor's extension store. Developers using third-party extension ecosystems should audit installed extensions and regularly rotate secret keys used across development services.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/11/stolen-fireworks-ai-key-led-to-cursor.html)</span>

## What to do this week

- Audit public-facing AI applications and ensure API management endpoints are secured behind proper authentication.
- Isolate industrial control hardware, including refrigeration systems, from direct public internet access.
- Apply Linux kernel updates on web and SSH servers to protect against remote denial-of-service flaws.
- Review third-party vendor access permissions and enforce multi-factor authentication across cloud integrations.
