### SonicWall Patches Actively Exploited SSL-VPN Vulnerability

SonicWall has released security fixes for seven flaws in SonicOS firewalls, including an authentication bypass tracked as CVE-2026-19868 that is currently being exploited in attacks. The issue allows attackers holding credentials for one login method to bypass SAML checks and multi-factor authentication on SSL-VPN logins. Firewall administrators should immediately apply the latest firmware updates to protect their networks.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/sonicwall-patches-exploited-sonicos-bug-that-weakens-vpn-logins/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-new-ssl-vpn-mfa-bypass-flaw-exploited-in-attacks/)</span>

### Attackers Target Newly Disclosed OpenSSH SSHole Vulnerability

Threat actors are actively trying to exploit a newly discovered OpenSSH vulnerability codenamed SSHole (CVE-2026-123158). On Linux systems running musl libc without PAM, the flaw reportedly lets attackers sign in to accounts that have no password set or accept specific password lengths to gain root access. Administrators should update OpenSSH installations immediately to block exploitation attempts.

<span class="brief-src">Sources: [The Hacker News](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html), [SecurityWeek](https://www.securityweek.com/openssh-rushes-patches-for-sshole-authentication-bypass/)</span>

### OpenAI Unveils GPT-6 Cyber Security Research Model

OpenAI introduced GPT-6 Cyber, a new artificial intelligence model designed to assist with defensive security research. The company states the model discovered 81 high-severity flaws in Firefox and developed working exploits for 948 Linux kernel vulnerabilities. OpenAI claims the model significantly improves on past versions by staying strictly within designated scope limits while searching for flaws.

<span class="brief-src">Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/openais-new-gpt-6-cyber-ai-finds-81-firefox-flaws-948-linux-bugs/), [The Hacker News](https://thehackernews.com/2026/11/openai-launches-gpt-6-cyber-after-ai.html), [SecurityWeek](https://www.securityweek.com/openai-says-new-gpt-6-cyber-model-hunts-flaws-without-crossing-the-line/)</span>

### AI Coding Tools Expose Sensitive Secrets and Local Files

Researchers revealed that developers approving automated commands in Claude Code accidentally published passwords and API keys across more than 1,000 public GitHub repositories. In a separate finding, security analysts demonstrated that malicious browser extensions could exploit Claude's Dispatch feature to run unauthorized code on a user's computer. Developers using AI coding tools should check public code repositories for leaked secrets and carefully audit installed browser extensions.

<span class="brief-src">Sources: [The Hacker News](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html), [The Hacker News](https://thehackernews.com/2026/11/malicious-browser-extensions-could-use.html)</span>

### DigiCert Reports Data Breach Exposing Customer Business Contact Data

Certificate provider DigiCert disclosed a data breach resulting from an internal business system left unintentionally accessible online over the summer. An unauthorized user created an account and accessed business customer names, email addresses, phone numbers, and physical addresses. Customer contacts should remain alert for targeted phishing attempts leveraging these details.

<span class="brief-src">Sources: [The Record](https://therecord.media/digicert-certificate-authority-reports-data-breach), [SecurityWeek](https://www.securityweek.com/digicert-data-breach-impacts-business-customer-information/)</span>

### Microsoft Paint Vulnerability Fix Available Only via Microsoft Store

Microsoft has patched a remote code execution vulnerability (CVE-2026-83844) affecting the Windows Paint application. Notably, the update is being distributed exclusively through the Microsoft Store app rather than standard Windows Update services. Windows users should open the Microsoft Store and manually update Paint to version 11.2609.401.0 or newer.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/11/microsoft-paint-rce-fix-now-available.html)</span>
