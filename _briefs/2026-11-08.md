### SonicWall Patches Actively Exploited SSL-VPN MFA Bypass Flaw

SonicWall has issued security updates across SonicOS firewalls to resolve seven vulnerabilities, including an SSL-VPN authentication bypass tracked as CVE-2026-19868. Attackers with valid credentials for an alternate login method can reportedly bypass SAML checks and multi-factor authentication requirements. The flaw is already being exploited in wild attacks, according to the vendor. System administrators should patch affected SonicOS appliances immediately to prevent unauthorized network access.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/sonicwall-patches-exploited-sonicos-bug-that-weakens-vpn-logins/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-new-ssl-vpn-mfa-bypass-flaw-exploited-in-attacks/)</span>

### Claude Code Settings File Exposes Secrets Across Public GitHub Repos

Anthropic's AI coding assistant, Claude Code, has reportedly caused sensitive credentials to appear in over 1,100 public GitHub repositories. When users accept commands with the 'Yes, and don't ask again' prompt, the tool can save passwords and API keys into a local file that developers unintentionally commit and publish. Developers who use Claude Code should verify whether their repositories contain these files, rotate any exposed secrets immediately, and update ignore rules to avoid committing local configuration data.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html)</span>

### French Bank Hit by $133 Million Cyber Heist via Service Provider

French cooperative bank Crédit Mutuel Arkéa was struck by a cyberattack conducted through a third-party service provider, enabling attackers to execute up to $133 million in fraudulent transactions. The bank reportedly had to suspend multiple systems to contain the intrusion and stop further unauthorized activity. The breach underscores the critical need for organizations to monitor and restrict access permissions granted to external vendors.

<span class="brief-src">Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-pull-off-133-million-french-bank-heist-via-service-provider/)</span>

### Gift Card Phishing Campaigns Impersonate Major Brands and Celebrities

Cybersecurity researchers have highlighted widespread scam operations that impersonate trusted brands and public figures to promote bogus gift card giveaways. The deceptive campaigns guide victims through fake verification steps that harvest personal information and quietly enroll participants into unwanted paid subscriptions. Users should remain cautious of unsolicited giveaway offers on social media and verify promotions exclusively through legitimate corporate channels.

<span class="brief-src">Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/ctm360-exposes-fake-gift-card-scams-exploiting-trusted-brands/)</span>

## What to do this week

- Apply the latest SonicOS firmware updates immediately to protect SonicWall appliances from exploited authentication bypass attacks.
- Inspect GitHub repositories for committed Claude Code configuration files, revoke any exposed API keys or passwords, and add tool settings to your project ignore lists.
- Avoid engaging with celebrity- or brand-sponsored gift card giveaways on social media, especially those asking for personal data or subscription sign-ups.
