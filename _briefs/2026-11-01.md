### Critical Flaw in LXD and MicroCloud Allows Client Impersonation

A maximum-severity vulnerability rated CVSS 10.0 in Canonical's LXD and MicroCloud allows network attackers to impersonate trusted clients without holding their private keys. An adversary only needs network reachability to the HTTPS API alongside the trusted client's public certificate to authenticate as them. Administrators operating affected environments should update their installations immediately and ensure administrative APIs are not exposed to untrusted networks.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/11/critical-lxd-and-microcloud-flaw-cvss.html)</span>

### Compromised Third-Party Script Drains Millions From Polymarket Traders

Attackers stole approximately $2.7 million from Polymarket traders after compromising an external page-speed script hosted by DebugBear. The altered script executed in the browsers of logged-in users, liquidating their active market positions and redirecting the proceeds to attacker-controlled wallets. Developers should regularly audit external JavaScript dependencies and enforce integrity mechanisms such as Subresource Integrity to prevent third-party code tampering.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/11/hackers-steal-about-27-million-from.html)</span>

### Northflank Platform Breach Leads to Misuse of Customer AI Keys

Cloud application hosting platform Northflank reported a security breach that resulted in unauthorized actors abusing AI API keys belonging to its customers. The company is urging users to rotate all secrets, tokens, and credentials currently stored within their accounts. Developers using Northflank should immediately revoke exposed API credentials, generate replacements, and check their upstream AI service accounts for unexpected billing or usage spikes.

<span class="brief-src">Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/northflank-security-breach-leads-to-abuse-of-customers-ai-api-keys/)</span>

### Chainalysis Customer Identity Data Exposed in Tool Intrusion

Blockchain analytics firm Chainalysis disclosed an intrusion into its internal tools that exposed customer names, email addresses, user IDs, and organizational roles. Attackers reportedly deployed offensive agentic techniques to access internal systems, although the company stated that core platforms and sensitive customer data remained unaffected. Registered users should stay cautious regarding potential phishing or impersonation scams leveraging this contact information.

### Threat Actors Chain Ivanti Connect Secure Flaws for Remote Root Access

The Cybersecurity and Infrastructure Security Agency has flagged two Ivanti Connect Secure vulnerabilities for active exploitation after attackers chained three flaws to obtain unauthenticated root execution. The exploit chain allows remote threat actors to compromise enterprise edge devices without needing valid credentials. Security teams using Ivanti appliances should review their environments against known indicators of compromise and install the latest vendor security fixes.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/10/attackers-chain-three-ivanti-connect.html)</span>

## What to do this week

- Rotate all API keys, database credentials, and secrets stored in Northflank hosting accounts.
- Apply vendor patches immediately for Canonical LXD, MicroCloud, and Ivanti Connect Secure appliances.
- Audit web applications for third-party scripts and implement Subresource Integrity (SRI) hashes to prevent unauthorized code injection.
