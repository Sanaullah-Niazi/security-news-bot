### Active Exploitation Targets Node2Shell and E-Commerce Flaws

CISA has added a critical Brotli library vulnerability known as Node2Shell alongside Adobe Commerce flaws to its Known Exploited Vulnerabilities catalog. Attackers are actively targeting these vulnerabilities to compromise online stores and execute unauthorized code, with honeypots logging widespread attack attempts. System administrators running affected e-commerce platforms or web applications should apply the latest vendor patches immediately.

### Tailscale Issues Urgent Patches for SSH Privilege Escalation Flaws

Tailscale released version 1.104.4 to resolve multiple security vulnerabilities within its built-in SSH server functionality. Details of the flaws were publicly disclosed prior to a fix, creating risks that compromised devices could escalate privileges to root and access unauthorized files on target servers. Administrators using Tailscale SSH are advised to update their installations right away.

<span class="brief-src">Sources: [The Hacker News](https://thehackernews.com/2026/10/tailscale-patches-ssh-flaws-that-could.html), [SecurityWeek](https://www.securityweek.com/tailscale-rushes-patches-after-uncoordinated-disclosure-of-tailworm-flaws/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/tailscale-warns-of-serious-ssh-flaws-allowing-root-privilege-escalation/)</span>

### GMO Group Urges Machine Shutdowns Following Cloud Breach

Japan's GMO Internet Group instructed customers to disconnect their systems and shut down computers using its Onamae Desktop Cloud service due to an ongoing cyber incident. The breach resulted in extortion and ransomware threats, which GMO refused to pay while offering up to $1 million for information leading to the arrest of the attackers. Users of the cloud desktop service should follow company guidance to isolate their systems.

<span class="brief-src">Sources: [The Hacker News](https://thehackernews.com/2026/10/japans-gmo-offers-1-million-bounty-to.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/japans-gmo-urges-customers-to-shut-down-pcs-amid-ransomware-threat/)</span>

### UNM Health System Operations Disrupted by Cyberattack

A cyberattack targeting the University of New Mexico Health Sciences Center caused widespread system outages across the network. The incident forced the hospital to briefly divert emergency ambulances to nearby facilities and suspend outpatient surgeries and appointments. Recovery efforts remain underway as the organization addresses the disruption to patient care.

<span class="brief-src">Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/unm-health-ransomware-attack-disrupts-patient-care-surgeries/), [The Record](https://therecord.media/university-of-new-mexico-hospital-diverts-cyber-incident)</span>

### AI Tools Utilized in Automated Attacks and Vulnerability Discovery

Security researchers revealed that an offensive entity dubbed CyberStrikeAI reportedly deployed 44 AI agents to automate cyberattack operations against targets in Japan. In lab tests, Anthropic reported that an unreleased AI model successfully discovered and chained vulnerabilities into working proof-of-concept exploits across multiple operating systems. These disclosures highlight the growing reliance on artificial intelligence for both attack execution and vulnerability research.

## What to do this week

- Update web applications, Brotli libraries, and Adobe Commerce installations to patch actively exploited flaws.
- Upgrade Tailscale to version 1.104.4 or higher to fix SSH privilege escalation vulnerabilities.
- Isolate and disconnect systems using affected remote desktop cloud services if advised by service providers.
- Audit server access logs for unusual automated activity or unauthorized administrative commands.
