### Massive Binance Hack Siphons Over $6 Billion in Digital Assets

Cryptocurrency exchange Binance confirmed a security breach affecting an estimated $6.3 billion in assets, with nearly $3 billion successfully frozen on-chain so far. Investigators linked the unauthorized intrusion to a compromised DevOps engineer laptop, and blockchain analysts reportedly attribute the attack to North Korean threat groups. Organizations should enforce strict hardware authentication and isolate privileged administrative systems to limit lateral movement.

### Critical Drupal Commerce Core Flaw Under Active Attack

Drupal issued an urgent warning that attackers are actively exploiting a critical authorization bypass vulnerability, tracked as CVE-2026-118539, in the Commerce Core module. The defect allows unauthenticated threat actors to circumvent security controls across online storefronts. Administrators running Drupal Commerce should install the latest security updates immediately and audit recent customer orders for fraudulent activity.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/drupal-commerce-core-vulnerability-exploited-against-online-stores/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/drupal-warns-of-critical-commerce-core-flaw-exploited-in-attacks/), [The Hacker News](https://thehackernews.com/2026/10/hackers-actively-exploit-highly.html)</span>

### Polymarket Halts Trading Following Website Supply Chain Breach

Prediction market platform Polymarket temporarily suspended trading after attackers compromised an integrated third-party monitoring service to distribute malicious JavaScript. The malicious script hijacked active user sessions, draining an estimated $2 million to $2.5 million into an attacker's cryptocurrency wallet. Users of the platform should revoke suspicious token allowances, clear active browser sessions, and inspect their transaction histories.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/2-million-drained-from-polymarket-traders-in-new-supply-chain-attack/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/polymarket-halts-trading-after-crypto-draining-script-breach-25m-traced/)</span>

### Max-Severity GitLab RCE Actively Exploited Against Servers

A maximum-severity vulnerability in GitLab, tracked as CVE-2026-97229, is under active exploitation by unauthenticated attackers seeking arbitrary code execution. The flaw has already been leveraged in attacks against Alpine Linux infrastructure and was subsequently added to CISA's Known Exploited Vulnerabilities catalog. Administrators running self-hosted GitLab servers must apply the vendor's emergency patches immediately.

<span class="brief-src">Sources: [SecurityWeek](https://www.securityweek.com/max-severity-gitlab-vulnerability-exploited-against-alpine-linux/), [The Hacker News](https://thehackernews.com/2026/10/cisa-adds-actively-exploited-gitlab-rce.html)</span>

### Compromised Claude Code Extension Distributes Persistent Backdoor

Researchers disclosed that the official Claude Code extension on the Open VSX registry was hijacked to install a persistent SSH backdoor on infected systems. The incident was reportedly linked to a compromise involving the Cursor editor ecosystem. Developers who downloaded the affected extension should inspect their authorized SSH keys, terminate unknown remote access credentials, and reinstall tools from verified repositories.

<span class="brief-src">Source: [The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html)</span>

## What to do this week

- Apply urgent security updates immediately to self-hosted Drupal Commerce and GitLab instances.
- Audit developer machines, VS Code extensions, and SSH authorized_keys files for unauthorized backdoors.
- Disconnect active wallet sessions and review token approvals on decentralized finance and trading platforms.
